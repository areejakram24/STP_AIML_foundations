# AIML Research Training & Foundations

This repository houses the complete codebase, practical lab tutorials, and evaluated assignments from my 5-month AIML Student Training Program (STP) at iHub-Data, IIIT Hyderabad.

The curriculum balanced rigorous mathematical theory with hands-on implementation, moving from classical machine learning baselines to deep neural network architectures.

## Repository Structure
* `/modules` — Theoretical implementations, foundational algorithms, and core ML concepts.
* `/tutorials` — Guided hands-on lab notebooks focusing on data engineering, evaluation metrics, and feature selection.
* `/assignments` — Independent programmatic milestones and problem-solving evaluations.

---

## Curriculum & Syllabus Breakdown

| Area | Core Topics & Mathematical Concepts Mastered | Technical Core / Implementations |
| :--- | :--- | :--- |
| **Foundations & Classification** | Introduction to ML pipelines (Data, Model, Evaluation), Nearest Neighbor Classification, Linear Classifiers, and Perceptrons. | Building classification pipelines; evaluating boundary conditions. |
| **Optimization & Loss** | Gradient Descent optimization algorithms, Loss Function engineering, and Parametric Regression models. | Implementing optimization loops from scratch; loss minimization. |
| **Unsupervised Learning & Feature Engineering** | Clustering algorithms, Dimensionality Reduction via Principal Component Analysis (PCA), and Feature Selection techniques. | Reducing high-dimensional datasets; clustering unstructured data. |
| **Text & NLP Basics** | High-dimensional data representation, vectorization, and Representing Textual Data for ML models. | Processing text features for classification tasks. |
| **Deep Learning & Probabilistic Models** | Multi-Layer Perceptrons (MLPs), Probabilistic ML models, and advanced Deep Learning Architectures. | Designing and training multi-layer neural networks. |
| **Evaluation Metrics** | Retrieval performance analysis, confusion matrices, precision, recall, F1-score, and comprehensive ML metrics. | Validating model reliability and performance optimization. |
